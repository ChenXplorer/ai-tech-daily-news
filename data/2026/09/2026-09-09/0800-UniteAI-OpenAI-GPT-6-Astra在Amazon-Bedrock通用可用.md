# GPT-6 Astra 在 Amazon Bedrock 达到通用可用

- 来源：Unite.AI / AWS
- 链接：https://www.unite.ai/openais-gpt-6-astra-reaches-general-availability-on-amazon-bedrock/
- 发布时间：2026-09-08 08:00 +08:00
- 抓取时间：2026-09-09 08:20 +08:00
- 标签：OpenAI、AWS、API

AWS 表示 GPT-6 Astra 已在 Amazon Bedrock 通用可用，可经 Bedrock API 调用，也可配置到 ChatGPT Work 与 Codex。Unite.AI 引述 OpenAI 标准 API 定价为输入 10 美元/百万 tokens、输出 50 美元/百万 tokens，Fast 模式为标准价 2 倍、速度约 2 倍。模型 ID 为 gpt-6-astra。
