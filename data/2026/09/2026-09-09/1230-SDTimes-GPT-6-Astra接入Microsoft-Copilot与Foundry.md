# GPT-6 Astra 接入 Microsoft Copilot 与 Foundry

- 来源：SD Times / Microsoft
- 链接：https://sdtimes.com/ai-models/openais-gpt-6-astra-now-available-in-microsoft-applications/
- 发布时间：2026-09-08 12:30 +08:00
- 抓取时间：2026-09-09 08:20 +08:00
- 标签：OpenAI、Microsoft、API

Microsoft 与 OpenAI 宣布，GPT-6 Astra 已可用于 Copilot Cowork、Copilot Studio、Microsoft Foundry 与 GitHub Copilot。此前该模型于 9 月 3 日发布，今日新闻为云与办公套件通用化。OpenAI 称同步更新 Codex harness，在 Mind2Web 基准上任务完成速度较 GPT-5.6 Sol 提升约 1.9 倍。
