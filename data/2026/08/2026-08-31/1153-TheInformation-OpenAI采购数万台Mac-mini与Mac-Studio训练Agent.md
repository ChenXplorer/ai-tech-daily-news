# OpenAI 被暴采购数万台 Mac mini 与 Mac Studio 用于 Agent 训练

- 来源：The Information（多家转述）
- 链接：https://eu.36kr.com/zh/p/3962892455804294
- 发布时间：2026-08-31 11:53 +08:00
- 抓取时间：2026-08-31 14:27 +08:00
- 标签：OpenAI、Apple、Agent、硬件

The Information 报道称 OpenAI 近月采购数万台 Apple Mac mini 与 Mac Studio，用于强化学习与计算机使用 Agent 训练，且仍在追供。报道同时称 Anthropic 选择经 AWS 租用 Mac 算力。OpenAI 与 Apple 均未公开确认该采购。多家转述将动因解读为统一内存架构适合多步界面操作的并行环境。
