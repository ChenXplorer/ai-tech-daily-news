# NaiveAI 发布开源权重模型 Naive-N0.5-Flash：309B MoE、原生 100 万上下文

- 来源：NaiveAI
- 链接：https://naive.ai/en/research/
- 发布时间：2026-09-27 16:00 +08:00
- 抓取时间：2026-09-28 07:55 +08:00
- 标签：AI、开源模型、LLM、NaiveAI

北京实验室 NaiveAI 于 9 月 27 日发布 Naive-N0.5-Flash。官方称该模型为 309B 总参数 MoE，每 token 激活约 15.5B，采用滑动窗口注意力与 DeepSeek Sparse Attention 混合、无全注意力层，原生支持 100 万 token 上下文，面向编程与 AI 研发。权重与推理代码以 MIT 协议开源。官方公布 API 定价为每百万 token 输入 0.10 美元、输出 0.40 美元、缓存读取 0.01 美元，但发布当日 API 尚未上线。公司自报 SWE-bench Pro 73.6 分等结果，独立复现尚未出现。
