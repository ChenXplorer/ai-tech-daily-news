# 报道：OpenAI 采购数万台 Mac mini/Studio 用于 Agent 强化学习

- 来源：The Information / AIBARS
- 链接：https://aibars.net/en/news
- 发布时间：2026-08-31
- 抓取时间：2026-09-01 07:55 +08:00
- 标签：OpenAI、Apple、算力

The Information 等报道 OpenAI 近月采购数万台 Mac mini 与 Mac Studio，用于强化学习与计算机操作 Agent 训练，依赖 Apple 统一内存架构；报道称已对供应产生压力。Anthropic 亦通过 AWS 租用 Mac mini。
