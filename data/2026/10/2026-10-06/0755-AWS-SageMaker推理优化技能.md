# 亚马逊发布面向编程智能体的SageMaker推理优化技能

- 来源：Amazon Web Services
- 链接：https://aws.amazon.com/blogs/machine-learning/new-agent-skill-amazon-sagemaker-optimized-generative-ai-inference-for-your-coding-agent/
- 发布时间：2026-10-05
- 抓取时间：2026-10-06 07:55 +08:00
- 标签：AI、云服务、应用、Amazon

亚马逊云科技10月5日在机器学习博客宣布，通过 Agent Toolkit for AWS 提供 aws-ai-ml 技能，让 Kiro、Claude Code、Codex 等兼容编程智能体生成 SageMaker Python SDK v3 代码，用于基准测试、部署配置推荐和推理性能对比。
