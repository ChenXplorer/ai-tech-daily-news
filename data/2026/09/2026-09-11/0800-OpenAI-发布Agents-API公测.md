# OpenAI发布Agents API公测，把Codex托管编排能力开放给开发者

- 来源：OpenAI
- 链接：https://openai.com/index/introducing-the-agents-api/
- 发布时间：2026-09-10 08:00 +00:00
- 抓取时间：2026-09-11 07:55 +08:00
- 标签：OpenAI、AI产品、API、智能体

OpenAI 9月10日宣布Agents API进入公测，开发者可用与Codex、ChatGPT for Work相同的托管编排层创建云端智能体。平台负责会话编排、长上下文压缩与恢复，支持MCP与并行子智能体。运行环境可选OpenAI托管沙箱或Cloudflare、E2B、Oracle、Vercel等伙伴。API本身不另收费，只按token与工具用量计费。
