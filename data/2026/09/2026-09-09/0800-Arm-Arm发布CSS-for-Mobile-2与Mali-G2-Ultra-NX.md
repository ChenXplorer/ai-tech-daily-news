# Arm 发布 CSS for Mobile 2 与 Mali G2-Ultra NX

- 来源：Arm Newsroom
- 链接：https://newsroom.arm.com/news/arm-css-for-mobile-2-agentic-ai-mobile-graphics
- 发布时间：2026-09-08 08:00 +08:00
- 抓取时间：2026-09-09 08:20 +08:00
- 标签：半导体、边缘AI、手机

Arm 发布面向 Agent 式 AI 与移动图形的 CSS for Mobile 2，包含首款内置神经加速器的 Mali G2-Ultra NX GPU 以及带 SME2 的 C2 CPU 集群。Arm 称神经图形能效最高提升约 4 倍，既有游戏性能提升约 14%。The Verge 报道该 GPU 已用于小米自研玄戒 O3，并提供 AI 超分与帧生成等能力。
