# 微软将 Copilot 重组为 Home、Code 与 Autopilot 三层

- 来源：Microsoft Blog / TestingCatalog
- 链接：https://blogs.microsoft.com/blog/2026/09/25/introducing-the-new-copilot-with-home-code-and-autopilot/
- 发布时间：2026-09-26 14:40 +08:00
- 抓取时间：2026-09-27 07:55 +08:00
- 标签：科技公司、AI 产品
- 重要性：中

微软官方博客 9 月 25 日宣布、9 月 26 日媒体跟进：Copilot 应用改为 Home（Chat+Cowork，并嵌入 Office）、Code（基于 GitHub Copilot 技术的低代码构建）和 Autopilot（原 Scout，可在用户离线时持续执行的企业智能体）。Home/Code 将先向 Frontier 计划推送，Autopilot 本月底扩大私有预览。部分报道称企业侧将按用量计费。
