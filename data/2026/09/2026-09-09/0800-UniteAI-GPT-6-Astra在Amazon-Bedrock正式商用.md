# AWS：GPT-6 Astra 在 Amazon Bedrock 正式商用，标准 API 报价输入 10 美元/百万 token

- 来源：Unite.AI / AWS / OpenAI
- 链接：https://www.unite.ai/openais-gpt-6-astra-reaches-general-availability-on-amazon-bedrock/
- 发布时间：2026-09-08 08:00 +08:00
- 抓取时间：2026-09-09 07:55 +08:00
- 标签：AI/LLM、云服务、商业化

AWS 于 9 月 8 日称 OpenAI GPT-6 Astra 已在 Amazon Bedrock 一般可用，可通过 Bedrock API 调用，也可配置 ChatGPT Work 与 Codex 使用该模型，并随企业插件上线。OpenAI 列出标准 API 价格为输入每百万 token 10 美元、输出 50 美元，另有缓存读写价；Fast 模式称最高约 2 倍速度、2 倍价格。Astra 已通过 OpenAI API、Azure 与 Bedrock 分发。模型首发于 9 月 3 日，本日新增的是 Bedrock 正式商用节点。
