# Anthropic 将 Claude Code 标准周额度永久上调 25%，相对当前促销额度净减约 17%

- 来源：Analytics India Magazine
- 链接：https://analyticsindiamag.com/ai-news/anthropic-cuts-claude-codes-usage-limits-by-17-after-slashing-promotional-boost
- 发布时间：2026-08-31 11:30 +08:00
- 抓取时间：2026-08-31 14:27 +08:00
- 标签：AI、LLM、Anthropic、产品定价

Anthropic 称自 2026 年 9 月 14 日起，Pro、Max、Team 及按席位计费的 Enterprise 方案，Claude Code 标准周额度将永久上调 25%。因当前仍叠加自 5 月起的 50% 临时促销，相对用户此刻可用额度，调整后约为净减少 17%。五小时滚动额度不变。公司未公布具体 token 数字。
