# AI Tech Daily News

用于按天保存自动抓取的 AI 与科技新闻，便于后续检索、去重、汇总和分析。

## 数据目录

新闻文件统一使用 Markdown 格式，按日期存放在 `data/YYYY/MM/YYYY-MM-DD.md`。例如：

```text
data/2026/08/2026-08-31.md
```

每天的文件建议使用以下格式：

```markdown
# AI 科技新闻日报｜2026-08-31

## 新闻标题

- 来源：来源名称
- 链接：https://example.com/news
- 发布时间：2026-08-31 08:00 +08:00
- 抓取时间：2026-08-31 09:00 +08:00
- 标签：AI、模型

新闻摘要。
```

## 基本约定

- 文件使用 Markdown 格式和 UTF-8 编码。
- 时间使用带时区的 ISO 8601 格式。
- 使用原始文章 URL 去重。
- 不提交密钥、令牌或本地配置文件。
