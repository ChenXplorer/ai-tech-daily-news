# OpenAI 发布 GPT-6.1 Terra，API 价格折半，强化电脑使用

- 来源：OpenAI / The Decoder
- 链接：https://openai.com/
- 发布时间：2026-10-26 +08:00
- 抓取时间：2026-10-27 07:55 +08:00
- 标签：AI、LLM、OpenAI、API

OpenAI 推出 GPT-6.1 Terra 中端模型，标准 API 价格为每百万 token 输入 1 美元、输出 5 美元，相比前代折半。该模型在视觉推理与电脑使用（表单填写、应用操作等）上表现强劲，性能接近更高端模型但成本大幅降低，已在 ChatGPT Work、Codex 与 API 上架。
