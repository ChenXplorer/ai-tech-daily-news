# Microsoft在Ignite发布多款MAI模型，主打高性价比编程与安全模型

- 来源：Microsoft AI / Reuters
- 链接：https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/
- 发布时间：2026-11-17
- 抓取时间：2026-11-18 07:55 +08:00
- 标签：AI、LLM、Microsoft、模型

Microsoft AI在Ignite发布七款新模型，包括MAI Code 2、Code 2 Flash、Cyber 2 Flash等。Code 2称在企业编程任务上达到GPT-6.1 Sol的98%性能、仅为其成本的40%，对Claude Opus 5.5为96%性能、5%成本。已在GitHub Copilot等中推出。
