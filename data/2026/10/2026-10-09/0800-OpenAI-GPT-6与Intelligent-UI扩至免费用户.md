# OpenAI 将 GPT-6 与 Intelligent UI 扩展至免费与 Go 用户

- 标题：OpenAI 将 GPT-6 与 Intelligent UI 扩展至免费与 Go 用户
- 摘要：OpenAI 10 月 7 日宣布，GPT-6 与 Intelligent UI 先向 Plus、Pro、Business、Enterprise 推送，10 月 8 日起扩至 Free 与 Go。付费档使用 GPT-6 Sol，免费与 Go 使用 GPT-6 Luna。公司称覆盖每周使用 ChatGPT 的超过 12 亿人。Intelligent UI 可在回复中生成图表、按钮、表单和交互式工具。本次更新仅针对 Chat 体验，Work 与 Codex 所用模型不在此次变更范围。
